# Samrakshana Yoga Kendra

Website for Samrakshana Yoga Kendra, a yoga therapy studio in Raja Annamalaipuram, Chennai, founded by R. Ramya.

Designed and built by The Zero Fluff Company.

- `index.html` — the site (GSAP + ScrollTrigger + Lenis from CDN)
- `journal/` — articles
- `img/` — photography and logo
- `llms.txt` — summary for AI assistants

Hosted with GitHub Pages from the `main` branch root.
